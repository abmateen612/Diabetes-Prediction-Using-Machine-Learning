# Diabetes Risk Prediction Model

## Overview

An end-to-end machine learning project for predicting diabetes risk
from health-related indicators using a large real-world dataset
containing more than **250,000 patient records**.

The project focuses not only on building a predictive model, but also
on comparing different machine learning approaches, optimizing model
performance, evaluating predictions using multiple metrics, and
interpreting model decisions.

## Project Objective

The main objective was to develop a machine learning pipeline that can
identify patterns associated with diabetes risk and compare different
models to determine which approach performs best on the dataset.

A second objective was to make the predictions more interpretable by
using SHAP to investigate which health indicators contribute to
individual model predictions.

## Dataset

The dataset contains more than:

**250,000 patient records**

and includes health-related indicators used as input features for
diabetes risk prediction.

The data was processed and prepared before being used for machine
learning.
